A modern, appetizing, responsive multi-page restaurant website designed for **Burger & Sandwich Joint**, specializing in signature smash burgers, gourmet deli sandwiches, crispy sides, combo deals, and handcrafted beverages.

## 3. Strict Layout & Design Rules Implemented

1. **Strict Card Count Rule**: Every card-based section across all 8 pages uses strictly an **even number of cards** (**4 cards** or **6 cards**). Never 3, 5, 7 or any odd number of cards.
2. **Distinct Home Page Designs**: `index.html` and `home-2.html` feature completely different hero layouts, section arrangements, and storytelling components.
3. **100% Unique Image Distribution**: All **109 images** (`image-1.png` to `image-109.png`) are uniquely mapped to matching culinary sections with **zero duplicate uses** and **zero omissions**.
4. **Interactive Features**:
   - Sticky navbar with blur backdrop and mobile drawer.
   - Dynamic JavaScript menu category filtering (`menu.html`).
   - Interactive Meal Builder with live pricing calculations (`combo-offers.html`).
   - Interactive Flavour Selector (`burgers.html`).
   - Expandable FAQ Accordion and validated Contact Form (`contact.html`).
   - Universal Product Detail Modal popup (`js-view-details`).
